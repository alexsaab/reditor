# ROADMAP: реализовано в reditor

| Возможность | Реализация |
| --- | --- |
| LSP / rust-analyzer | Диагностика, автодополнение, типы и документация, определения, использования, переименование и исправления с просмотром. |
| Поиск и замена | Замена в файле и проекте, фоновые результаты с переходами, исключение артефактов, просмотр перед применением. |
| Восстановление работы | Вкладки, курсоры, прокрутка, резервная копия несохранённых буферов и проверка конфликтов на диске. |
| Палитра и быстрое открытие | Ctrl+P для файлов, Ctrl+Shift+P / Ctrl+G для команд и плагинов; фильтрация по части имени. |
| Выбор проекта | Браузер папок с переходом по каталогам, возвратом на уровень выше и переключением проекта с восстановлением его сессии. |
| Разделение окна | Два редактируемых файла, исходник рядом с Markdown или Mermaid, обновление просмотра, изменение ширины областей и проводника перетаскиванием мыши или командами. |
| Git | Ветка, отметки изменённых строк, список файлов, сравнение, выбор файла для индекса и коммит. |
| Rust-проекты | Пакеты workspace, bin-цели, сборка, запуск, тесты, Clippy, check, debug/release, аргументы, stdin, переходы из вывода. |
| Настройки | Темы, сочетания клавиш, отступы и перенос строк; размер шрифта средствами терминала. |
| Плагины | API версии 1, настройки, команды и горячие клавиши, нижние текстовые панели и ошибки загрузки. Lua/JS/TS поддерживаются. |
| Диаграммы | Экспорт SVG/PNG, выбор схемы, поиск подписи, список строк связей и прокрутка к узлу. |
| Нижняя панель терминала | PTY, оболочка, вкладки задач и процессов, ANSI/Unicode, интерактивный ввод, история, остановка и изменение высоты мышью или командами. |

Управление и ограничения описаны в [docs/WORKBENCH.md](docs/WORKBENCH.md).
Текстовый Mermaid отображает контуры приближённо. Поиск ограничен размером индекса и UTF-8 файлами. LSP snippets, файловые операции исправлений и передача мыши вложенным терминальным приложениям остаются отдельными расширениями.

За пределами исходного плана: отладчик DAP, regex-поиск, другие кодировки, перемещение узлов диаграммы мышью, Git-конфликты и интерактивные rebase.

В версии 0.3 добавлены Lua-плагины PHP, Git и FTP/SFTP/FTPS, установка для пользователя или проекта, объединение настроек `.reditor`, удалённые каталоги и фоновое сохранение файлов с проверкой конфликтов. Инструкция: [docs/PLUGINS_REMOTE.md](docs/PLUGINS_REMOTE.md).

В версии 0.4 добавлены левая панель значков плагинов и Lua-плагин форматирования Rust, PHP, JS/TS, HTML, CSS, JSON, Markdown и других форматов. Доступны ручное форматирование, проверка с просмотром различий и включаемое форматирование при сохранении. Инструкция: [docs/FORMATTER.md](docs/FORMATTER.md).

Открытые папки теперь попадают в список недавних проектов; Ctrl+Alt+P открывает список, Ctrl+Alt+O — другую папку, а при переключении восстанавливается сессия проекта. Lua-плагин проверки орфографии и грамматики подчёркивает ошибки в `.txt` и прозе `.md` для RU/EN/DE/ES; инструкция: [docs/PROOFREADER.md](docs/PROOFREADER.md).

Проверка текста по умолчанию определяет язык документа автоматически и показывает выбранный язык в строке состояния. В настройках можно закрепить язык или выбрать его вручную через команды плагина.
