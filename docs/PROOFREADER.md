# Орфография и грамматика

Плагин `proofreader` проверяет обычный текст в `.txt` и прозу в `.md` на русском, английском, немецком и испанском. Язык текста определяется автоматически; язык интерфейса на него не влияет. Markdown-разметка, кодовые блоки, встроенный код и адреса ссылок в проверку не попадают. Ошибки в исходнике подчёркиваются: красным отмечается орфография, голубым — грамматика. Через команду проверки открывается список ошибок с объяснениями и предложениями; Enter переводит курсор к нужному месту. Проверка в фоне запускается после паузы в наборе текста около 1,5 секунды. Устаревшие результаты после редактирования не показываются. Определённый язык отображается справа в строке состояния.

Для работы нужен **Java 17+** и локальная [LanguageTool 6.6](https://github.com/languagetool-org/languagetool/blob/master/languagetool-standalone/README.md). Текст передаётся только локальному процессу Java. На этой машине LanguageTool уже установлен в `~/.reditor/tools/languagetool`.

```sh
cd /Users/alexeyagafono/code/reditor
cargo run --release -- --install-plugin proofreader --scope user
cargo run --release -- . --lang ru
```

Для установки LanguageTool на другой машине скачайте [официальный архив](https://languagetool.org/download/LanguageTool-stable.zip), распакуйте его в `~/.reditor/tools/languagetool` так, чтобы там оказался `languagetool-commandline.jar`, и установите плагин указанной выше командой. Можно хранить JAR в `<проект>/.reditor/tools/languagetool` либо указать путь в настройках:

```toml
[plugin_settings.proofreader]
# language = "ru" # закрепить язык фоновой проверки; по умолчанию auto
# jar = "/путь/к/languagetool-commandline.jar"
# java_binary = "java"
```

Для разовой проверки с автоопределением выберите `proofreader.auto` через Ctrl+Shift+P, Ctrl+G или значок **PR** слева. Там же можно явно выбрать `proofreader.ru`, `proofreader.en`, `proofreader.de` или `proofreader.es`; `proofreader.current` использует язык интерфейса. Ctrl+P ищет файлы.

Язык выбирается для текста документа целиком. Короткие или смешанные фразы могут определяться неверно; в таком случае выберите язык вручную либо закрепите его в `[plugin_settings.proofreader]`. Если определился язык вне этих четырёх, редактор пропустит автоматическую проверку, чтобы не подчёркивать слова по неверному словарю.

Проверяются файлы размером до 128 КиБ. Подчёркивание терминала зависит от шрифта и терминальной программы и обычно выглядит как прямая линия, а не волнистая линия Word. Для Markdown отметки видны в режиме редактирования исходника.
