# Плагины reditor

Каждый плагин — каталог с `plugin.toml` и точкой входа `.lua`, `.js` или `.ts`. Плагин выполняет преобразование документа и возвращает результат либо декларативный запрос к функциям редактора. Lua не получает прямого доступа к файловой системе или процессам; действия PHP, Git и удалённых файлов выполняет редактор через capabilities. [Установка и готовые Lua-плагины](../docs/PLUGINS_REMOTE.md).

```toml
name = "My plugin"
api_version = 1
entry = "main.ts"
icon = "✦"
hooks = ["before_save", "on_open"]

[[commands]]
id = "my-command"
title = "My command"
key = "Alt+m"

[settings]
prefix = "Hello"
```

`hooks` и `icon` можно опустить. `icon` занимает не более двух колонок терминала и показывается в левой панели значков; нажатие открывает команды плагина. `commands` также отображаются в палитре `Ctrl+Shift+P`. Имена плагинов должны быть уникальными, идентификаторы команд уникальны внутри плагина. Точка входа должна находиться внутри его каталога.

```sh
reditor . --plugins /path/to/my-plugin
reditor . --plugins /path/to/plugins --plugins /another/plugin
```

Редактор предоставляет контекст:

```ts
interface EditorContext {
  event: string;          // id команды, "before_save" или "on_open"
  text: string;          // полный текущий текст
  path: string | null;   // путь файла; null для новой вкладки
  language: string;      // "ru", "en", "de", "es"
  apiVersion: 1;
  settings: Record<string, unknown>; // manifest + общие/проектные plugin_settings
}
interface EditorResult {
  text?: string;         // заменить документ; отсутствует — оставить текст
  message?: string;      // сообщение в строке состояния для команд
  panel?: { title: string; content: string }; // нижняя текстовая панель
  action?: { kind: "php" | "git" | "remote" | "format" | "proofread"; command: string }; // требует capabilities
}
```

JavaScript/TypeScript используют функцию `module.exports`:

```ts
module.exports = (ctx: EditorContext): EditorResult => {
  if (ctx.event !== 'my-command') return {};
  return { text: ctx.text.replaceAll('\t', '    ') };
};
```

Добавьте определения интерфейсов непосредственно в `.ts`, как в [uppercase-ts/main.ts](uppercase-ts/main.ts). Внешние импорты, `require`, Promise и асинхронные обработчики не поддерживаются. Типы удаляются средствами Node.js; проверка типов не выполняется. Функции TypeScript, требующие генерации кода, и зависимости нужно предварительно собрать в самостоятельный JS bundle с форматом CommonJS.

Lua возвращает функцию из файла:

```lua
return function(ctx)
    if ctx.event == "my-command" then
        return { text = ctx.text:gsub("\t", "    ") }
    end
    return {}
end
```

В комплекте: `trim` (Lua, удаление пробелов в конце строк, также `before_save`), `header-js` (вставка комментария), `uppercase-ts` (верхний регистр).

Пример нижней панели с настройками и горячей клавишей: [examples/panel-plugin](../examples/panel-plugin). Запуск: `reditor . --plugins ./examples/panel-plugin`, затем Alt+S или Statistics в палитре Ctrl+G. Отсутствующий api_version означает 1; неизвестная версия вызывает ошибку загрузки. Ошибки видны в строке состояния, F5 повторяет загрузку. Настройки manifest применяются через F5. Панели текстовые; результат panel используется командами, hooks продолжают работать с текстом.

`on_open` вызывается после чтения нового файла, результат становится несохранённым изменением. `before_save` получает путь назначения; обработчики выполняются по порядку каталогов `--plugins`, затем по именам каталогов. Текст результата одного обработчика получает следующий. Если любой обработчик завершается с ошибкой, цепочка не применяется и файл не сохраняется. Для сообщений из hooks используйте команды: `message` в hooks не отображается.

Каждое выполнение создаёт новый контекст. Состояние между командами не сохраняется. Lua ограничен 32 MiB и примерно 500 мс исполнения Lua-инструкций; `io`, `os`, `package`, `debug`, `require`, `dofile`, `loadfile` отключены. JS работает в отдельном Node-процессе с лимитом heap 64 MiB, таймаутами `vm` 500 мс и общим таймаутом процесса 3 секунды. Ответы ограничены 2 MiB. Плагины блокируют ввод на время вызова; бесконечный цикл прерывается, ошибка появляется в строке состояния.

Эти ограничения помогают избежать зависаний, но **не обеспечивают безопасное исполнение недоверенного кода**: Node `vm` не является защищённой песочницей. Подключайте плагины, исходники которых вы проверили. Редактор автоматически загружает плагины из пользовательской и проектной `.reditor/plugins`; при одинаковом имени приоритет имеет `--plugins`, затем проект, затем пользователь.

`capabilities=["php"]`, `["git"]`, `["remote"]`, `["format"]` или `["proofread"]` разрешают соответствующие host actions. Их перечень ограничен редактором; автоматические hooks не могут выполнять action. `titles={ru="...",en="...",de="...",es="..."}` переводит название команды. Существующие плагины API 1 продолжают работать.
